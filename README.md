# Iftikhar Mirza Personal Portfolio

This is the first production-ready version of Iftikhar Mirza's personal portfolio website.

## Files
- `index.html` — website structure/content
- `style.css` — responsive premium  styling
- `script.js` — navigation, theme switch, scroll animations
- `images/` — supplied profile/gallery photos
- `assets/iftikhar-cv.pdf` — supplied CV
- `robots.txt` / `sitemap.xml` — search-engine basics
- `favicon.svg` — browser icon

## GitHub
Repository: `iftikharmirza99/portfolio`

## Cloudflare Pages
After uploading these files to the repository:
1. Open Cloudflare Dashboard.
2. Pages > Create a project.
3. Connect GitHub and select `iftikharmirza99/portfolio`.
4. Framework preset: None.
5. Build command: leave empty.
6. Build output directory: `/` (root).
7. Deploy.

Cloudflare will provide a free `*.pages.dev` address. Later, a custom domain such as `iftikharmirza.pk` can be connected.
